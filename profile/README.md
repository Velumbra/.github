# Velumbra

Velumbra develops software: well-made applications for different uses, from a sailing club's courses and boats to a planner that rotates people through groups.

The name and the mark come from the sunset eclipse over Mallorca on 12 August 2026: the sun going down into the sea with the moon across it, a red sail above the waves.
